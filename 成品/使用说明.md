## 一、这个目录里有什么

| 文件 | 是什么 | 干什么用 |
|---|---|---|
| `Minecraft-…-v20a-4px.apk` | **底包 A：原版 Steve + 粗手臂(4px)** | **想锁 4px 就装它** |
| `Minecraft-…-v20b-3px.apk` | **底包 B：原版 Alex + 细手臂(3px)** | **想锁 3px 就装它** |
| `Minecraft-…-offline-v19.apk` | **根底包**：能离线玩的网易版 | **长期保存 + 改包的源包** |
| `MCPatchTool-v26.10.10-1010-1848.apk` | **改包工具**（0.3 MB，不是游戏） | 改名字 / 换皮肤 / 加资源包 / 导入世界 / **换手臂粗细** |
| `Minecraft-…-import.apk` | 老包（v19 + 导入按钮 + Miku） | 已被 v20a/v20b 取代，可删 |

**五个游戏包同一把密钥签名** → 可互相**直接覆盖安装**，不用卸载、不丢存档 ✔

**底包 = 离线补丁 + 自带「导入世界」按钮 + 原版 Steve/Alex 贴图 + 官方玩家名（史蒂夫 / 艾莉克斯）**

> ⚠️ **请把 `v19` 那个文件另存一份**（网盘 / U 盘 / 另一台电脑）——
> 它是根，丢了就只能从官方原版重做整条离线补丁。

## 二、只想玩：装 v20a 或 v20b

两个包唯一的区别是**手臂粗细**，而这个选择在**全新安装时定死**，以后覆盖安装改不了
（原因见第五节）：

| 装哪个 | 得到 |
|---|---|
| **v20a** | 原版 **Steve** 皮肤 + **4px 粗手臂** |
| **v20b** | 原版 **Alex** 皮肤 + **3px 细手臂** |

**推荐用法（以后换皮肤再也不用卸载）：**

```
① 卸载游戏（⚠️ 先看第六节备份！）→ 装 v20a 或 v20b   ← 这一步决定手臂粗细
② 以后换皮肤 / 改名 / 加资源包 → 用工具生成 → 直接覆盖安装
   → 贴图立刻就变 ✔，手臂粗细保持底包那个 ✔
```

想确认手臂粗细：进游戏 → **角色界面**（不用进世界），3D 预览一眼能数出来。

## 三、改名字 / 换皮肤 / 加资源包（工具第 1–4 节）

1. 打开 `MCPatchTool`，**选源 APK → 选 `v20a` 或 `v20b`**（⚠️ 别选官方原版：会丢掉离线补丁）
2. 勾「改名」/「换皮肤」/「加资源包」；**第 3 节里的手臂选项跟着底包选**
   （底包是 v20a 就选粗、v20b 就选细）
3. 「一键生成 APK」→ 生成完点「立即安装」（会先弹一句提醒，看完再装 ✔）

工具**只改这 5 类文件**：`Base/*.png`、`Base/skindefs.json`、两个 `texts/*.lang`、
`assets/web/index.html`（注入导入按钮）、你的资源包。
`classes.dex`、`resources.arsc`、`AndroidManifest.xml`、`lib/*.so` **逐字节原样搬运**
—— 这就是离线能力不会丢的原因。

## 四、导入外部世界（`.mcworld`，工具第 5 节）

```
① 工具里：选 .mcworld → 勾「自动降级」→ 点「准备导入」
② 打开游戏 → 点左下角「导入世界」→ 等它显示"导入完成"
③ 完全退出游戏 → 重新打开 → 世界出现在列表里
```

工具会把包**登记成图片**（后缀 `.png`）写进 `Download/`，游戏就能按路径读到。

> **为什么必须伪装成 `.png`**：Android 11+ 规定别的 App 创建的**非媒体文件**（`.zip`）
> **任何位置、任何权限都读不到**；媒体文件才能按路径读。
> （实测：未 root 的 Android 15 上 `.zip` 放四个位置全是 `Errno 13`，换 `.png` 立刻通过。）
> ⚠️ `Download/` 里的 `mcweb_*` / `mcarm_*` 是给游戏读的，**别删**（游戏用掉后自己就消失）。

## 五、换手臂粗细（3px ↔ 4px）

**结论：手臂粗细只在"全新安装"时定一次，之后覆盖安装永远不变。**
所以两条路：

| 情况 | 怎么做 |
|---|---|
| **一般用户（不用 root）** ⭐ | 工具 **第 6 节「换手臂粗细（推荐 · 不用卸载）」** → 点「切成 3px」或「切成 4px」→ 打开游戏（左下角有提示）→ **完全关掉游戏** → 重开 |
| 有 root 的手机 | 退出游戏后改 `options.txt` 里的一行（见下） |

**为什么这么绕**：游戏里是**两套配置** ——

| | 存在哪 | 什么时候读 |
|---|---|---|
| **皮肤贴图** | APK 里的 `Base/*.png` | **每次启动都读** → 覆盖安装立刻生效 ✔ |
| **手臂体型** | 游戏私有目录的 `options.txt` | **只在首次运行时写一次** → 改 APK 不生效 ✗ |

有 root 的话，改这一行即可（不用卸载、不丢存档）：

```bash
OPT=/data/data/com.netease.mc.qihoo/games/com.netease/minecraftpe/options.txt
adb shell su -c "sed -i s/game_skintypefull:Standard_Alex/game_skintypefull:Standard_Steve/ $OPT"  # 切 4px
adb shell su -c "sed -i s/game_skintypefull:Standard_Steve/game_skintypefull:Standard_Alex/ $OPT"  # 切 3px
```

> ⚠️ **第 6 节会重置游戏设置**（画质 / 视野 / 控制 / 语言回到模板值）——
> 游戏 H5 只能整份覆盖这个文件，读不出你原来的设置（模板已把按钮尺寸设为 80）。
> ⚠️ 期间**别在游戏运行时覆盖安装 APK** —— 安装会杀掉游戏，它会把内存里的旧配置存回去。

## 六、两条铁律

### 1. 别换签名密钥

一旦用某把密钥装过改包，以后就必须一直用同一把 —— 否则系统拒绝覆盖安装，
只能卸载重装 = 又踩第 2 条。密钥在 `../mc-tool/app/src/main/assets/mc-patch-key.pk8`，
**另外备份一份**。

### 2. 卸载游戏之前，一定先备份 `Android/data/`

⚠️ 这版游戏**没有「导出世界」菜单**（齿轮只打开「世界设置」，实测确认）；
而**卸载会静默清空 `Android/data/com.netease.mc.qihoo/`**，存档就在里面。

| 途径 | 怎么做 |
|---|---|
| **Shizuku + MT管理器**（推荐） | 装 [Shizuku](https://shizuku.rikka.app/) 用「无线调试」激活 → MT管理器开 Shizuku 模式 → 进 `Android/data/com.netease.mc.qihoo/` 整个复制出来 |
| **电脑 adb** | 手机开无线调试 → 电脑操作。⚠️ **直接 `adb pull` 会静默失败**，要先打包： |

```bash
adb shell "cd /sdcard/Android/data/com.netease.mc.qihoo/files/games && tar czf /sdcard/b.tgz com.netease"
adb pull /sdcard/b.tgz
adb shell rm /sdcard/b.tgz
```

要备份的核心是两个地方（整个 `com.netease` 才 ~10 MB，全备份最省事）：
`.../files/games/com.netease/minecraftWorlds/`（世界本体）
和 `.../storge/stream/resource_management/world_records/`（世界记录，列表靠它）。

> **Shizuku/adb 只能备份，不能用来导入新世界**：`shell` 在 `ext_data_rw` 组里，
> 只有「组可写」的目录才能新建文件，而 `minecraftWorlds/`、`world_records/` 都是组不可写
> （`chmod` 也改不了）。⇒ **导入新世界只能用工具那条 H5 通道**；
> 从备份还原时，把世界目录**打成 zip 再用工具导入** ✔

## 七、出问题怎么办

| 现象 | 原因 / 处理 |
|---|---|
| 用工具改了手臂粗细，进游戏没变 | 正常 —— 要**完全关掉游戏再打开**（`options.txt` 只在启动时读）；且手机上装的改包必须是**新版工具生成的**（含 H5 脚本） |
| 手臂点完完全没反应 | 装的改包是**旧版**（没有 H5 脚本）→ 用现在的工具重新生成一个再装 |
| 点「导入世界」全报 `Errno 13` | 用了**旧版工具**（写成了 `.zip`）。必须伪装成 `.png`，用新版重新「准备导入」 |
| 点「导入世界」说"没有找到待导入的包" | 还没点「准备导入」，或上次的包已被游戏消耗（正常，重跑一次） |
| 导入后列表里没有 | **没重启游戏**（世界记录只在启动时读一次） |
| 列表白屏 | 有"孤儿记录"（记录指向的世界目录不存在） |
| 导入的世界没地形 | `db/` 没进去。工具已按顶层目录分组处理；手工操作才会踩到 |
| 拒绝加载世界，提示"更新版本的该游戏保存了这一等级" | 存档版本比客户端新，导入时勾「自动降级」 |
| 名字变成 Miku | 用 v19 当源包了（它的玩家名被改成过 Miku）→ 改用 v20a/v20b，或用工具「改名」 |
| 工具里源包显示"结构：不像网易版" | 选错文件了（比如选成了工具自己的 APK）→ 重新选 v20a/v20b/v19 |

## 八、导入世界的已知坑（2026-10-10 已修）

| 现象 | 说明 |
|---|---|
| 点「导入世界」提示「**没有找到待导入的包**」✗ | **成功导入后再点就会这样** ✔ —— 包已被吃掉 ✔，属正常 ✔。**只点一次** ✔ |
| 点「准备导入」弹「导入准备失败」✗ | 旧版工具的 bug ✔，**已修** ✔。请用最新工具 ✔ |
| 工具显示已准备好 ✗，游戏里还是导入不了 ✗ | 旧版遗留的**半截包**挡住了扫描 ✔，**已修** ✔（新版每次准备导入会先清干净 ✔）|

**正确流程**（照这个来就不会踩 ✔）：

`
① 工具 → 展开「▸ 5. 导入外部世界」→ 选 .mcworld → 勾「自动降级」
② 点「② 准备导入」→ 等它显示「✅ 已准备好」（可以重复点 ✔ 会自动清干净 ✔）
③ 打开游戏 → 点【一次】「导入世界」→ 看到 🎉 导入完成！
④ 完全退出游戏 → 重开 → 世界出现在列表里
`
