# 网络屏蔽指南（不装补丁也能用的兜底方案）

目标：**WiFi 一直开着**，但让游戏访问不到网易那批 2017 年已经下线的接口，
从而自动落到你**已经验证过可以正常玩**的离线分支。

原理：`hosts_netease_block.txt` 把这些域名指到 `127.0.0.1`。
连接会被**立刻拒绝**（不是等超时），游戏马上走错误分支，
所以启动速度会比真断网还快。

---

## 方案 A：有 Root（推荐，最彻底）

### A-1 Magisk / KernelSU 模块（推荐，OTA 后不会丢）

在手机上用任意文件管理器建目录，或用 Termux：

```bash
su
mkdir -p /data/adb/modules/mc_offline_block/system/etc
cp /sdcard/hosts_netease_block.txt /data/adb/modules/mc_offline_block/system/etc/hosts

cat > /data/adb/modules/mc_offline_block/module.prop <<'EOF'
id=mc_offline_block
name=MC Offline Net Block
version=1.0
versionCode=1
author=you
description=Blackhole dead NetEase MC 2017 CDN hosts so the game falls back to offline mode
EOF

# 生效
chmod 644 /data/adb/modules/mc_offline_block/system/etc/hosts
reboot
```

> 注意：模块里的 `system/etc/hosts` 会**整体覆盖**系统 hosts。
> 如果你原本已经有别的 hosts 内容（去广告等），请先把它们合并进同一个文件。

### A-2 直接改系统 hosts（临时、重启后可能被还原）

```bash
su
mount -o rw,remount /system        # Android 10+ 可能是 / 或 /system_root
cp /system/etc/hosts /sdcard/hosts.backup     # 先备份！
cat /sdcard/hosts_netease_block.txt >> /system/etc/hosts
mount -o ro,remount /system
```

**回滚**：`su -c "cp /sdcard/hosts.backup /system/etc/hosts"` 后重启。

### A-3 用 LSPosed 直接挂钩（你有 LSPosed 的话）

比改 hosts 更精准，不碰系统文件。写个最小 Xposed 模块，勾选本游戏，钩两个方法：

```java
XposedHelpers.findAndHookMethod("com.mojang.minecraftpe.mcWebViewDialog",
        lpparam.classLoader, "set_loadurl", String.class,
        new XC_MethodHook() {
    @Override protected void beforeHookedMethod(MethodHookParam p) {
        p.args[0] = "file:///android_asset/storge/asset/networkerror.html";
    }
});
XposedHelpers.findAndHookMethod("com.mojang.minecraftpe.mcWebViewDialog",
        lpparam.classLoader, "load_url", String.class, /* 同上 */);
XposedHelpers.findAndHookMethod("com.mojang.minecraftpe.mcWebViewDialog",
        lpparam.classLoader, "try_load_url", String.class, /* 同上 */);
```

只改参数、不 return，所以不会出现 `.register/.locals` 那种重打包崩溃问题。

## 方案 B：没有 Root

用**本地 VPN 类**应用（自己实现一个 127.0.0.1 的 DNS/黑洞，不需要 root）：

| 应用 | 做法 |
|---|---|
| **RethinkDNS** | 自定义规则里加 `*gdl.netease.com`、`*update.netease.com` 等 → Block |
| **NetGuard** | 高级选项 → 自定义 hosts 文件，指向上面那份 |
| **personalDNSfilter** | 把域名加进 blacklist |
| **AdAway（VPN 模式）** | 自定义重定向到 127.0.0.1，导入上面的域名 |

装好后确认 VPN 图标常驻，再启动游戏。

## 方案 C：路由器层面（一劳永逸，全家设备生效）

- OpenWrt / Padavan / Merlin：把上面那些域名写进 `dnsmasq` 配置：
  ```
  address=/gdl.netease.com/127.0.0.1
  address=/update.netease.com/127.0.0.1
  address=/drpf.x.netease.com/127.0.0.1
  address=/pub.seadra.netease.com/127.0.0.1
  address=/matrix.netease.com/127.0.0.1
  address=/gph.netease.com/127.0.0.1
  ```
  然后 `/etc/init.d/dnsmasq restart`。
- 或者 AdGuard Home / Pi-hole：添加自定义过滤规则 `||gdl.netease.com^` 等。

> `address=/xxx/127.0.0.1` 是**后缀匹配**，所以 `gdl.netease.com` 会顺带覆盖
> `g79.gdl.netease.com`、`g0.gdl.netease.com`。

## 验证屏蔽是否生效

手机（Termux 或 adb shell）：

```bash
# 期望解析到 127.0.0.1
ping -c 1 g79.gdl.netease.com
getprop | grep -i dns        # 确认没被改回

# 期望立刻 Connection refused，而不是超时
curl -v --max-time 5 http://g79.gdl.netease.com/
```

在电脑上：

```powershell
Resolve-DnsName g79.gdl.netease.com
```

如果解析到 `127.0.0.1`，说明 hosts/dnsmasq 生效。

## 注意事项

1. **不要**图省事直接 `127.0.0.1 netease.com` 把整个网易域名段封掉。
   批量黑洞可能让 SDK 初始化时"每个接口都要等一次失败"，
   反而拖慢启动（虽然 127.0.0.1 是快速失败，通常没事）。
   按 `hosts_netease_block.txt` 的粒度来。
2. 改 hosts **前先备份**，方案 A-2 的回滚命令请记牢。
3. hosts 屏蔽 + 本补丁**可以同时用**：补丁管"万一还是弹了不显示 XML"，
   hosts 管"根本别弹"。两个一起上是最稳的组合。
4. 这套做法会同时让**游戏账号登录、资源下载、充值、公告**全部不可用 ——
   这是预期的，因为网易那边 2017 年的这批后端本来就已经下线了，
   并不是被你的屏蔽"弄坏"的。
